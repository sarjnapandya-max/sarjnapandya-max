## Projects

### 🔒 [Cloud-Based Secure Digital Vault](https://github.com/sarjnapandya-max/cloud-based-secure-digital-vault)
> Zero-knowledge cloud storage — the server cannot read your files.

Built a privacy-first cloud storage system where files are encrypted **before** they leave your device.

- AES-256 client-side encryption with PBKDF2 key derivation
- JWT + bcrypt authentication system
- Expiring UUID-based share links — recipients don't need an account
- Security validated against NIST standards using the STRIDE threat model
- Integrated AWS S3 for encrypted storage, MongoDB for metadata

`Python` `MERN Stack` `AWS S3` `JWT` `bcrypt` `AES-256` `MongoDB`

### 🎬 [Movie Success Predictor](https://github.com/sarjnapandya-max/Predict-Movie-Success)
> Predicts box office performance before a film releases.

End-to-end data mining system that analyses budget, genre, cast popularity, and audience ratings to forecast whether a movie will succeed or fail.

- Real-time predictions via a Django web interface
- Data pipeline from raw dataset to live output

`Python` `Django` `HTML/CSS` `Data Mining`
